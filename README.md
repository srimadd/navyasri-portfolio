# Navyasri Maddukuri — Professional Portfolio

A responsive, animated, single-page portfolio designed around the navy/slate visual language of the supplied resume, with a restrained futuristic cloud/platform aesthetic.

## Features
- Animated cloud/network hero
- Interactive 3D system card
- Scroll reveal and metric counters
- Responsive experience timeline
- Research and publication showcase
- Education and AWS credential section
- Accessibility-friendly reduced-motion support
- No external framework or JavaScript dependency

## GitHub Pages
Upload `index.html` and `favicon.svg` to a GitHub repository, then enable GitHub Pages from the repository settings.
